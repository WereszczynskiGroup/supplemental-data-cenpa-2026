Modify and execute the 'loop_script_generator.py' script to obtain command line outputs for specific residue ranges. Then, copy the output into .tcl scripts similar to the ones in the
'loop_HBonds_calc_scripts/' directory. Open the trajectory to be analyzed in VMD. Use the built-in Tk console in VMD to execute these .tcl scripts (example usage: source 'YOUR_TCL_SCRIPT.tcl') to generate the 'detail', 'log', and 'hbonds' data found in 'results/AA_HBonds_raw_data/'. Then use or modify the provided Jupyter notebook scripts in each system directory to generate the per-residue hydrogen bonds plots, colored by histone of origin shown in SI Figures 6-9A.
