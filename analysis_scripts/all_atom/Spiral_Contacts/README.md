Get PDB files of each system ready to use as a reference for contacts calculations. Also combine all runs of a single system into one trajectory called 'total.xtc'. Run the calculations scripts in 'contacts_calc_scripts/' to generate the '{system}\_tail_contacts_inside_outside_freq_SEM.dat' outputs in the 'results/AA_Spiral_Contacts_raw_data/' directory. Finally, just execute the 'plot_spiral_all_atom.ipynb' Jupyter notebook to plot the data as seen in SI Figure 12. To visualize a stepwise cumulative representation of the data, just execute the 'plot_stepwise_cumulativecontacts_AA.ipynb' notebook to get a plot similar to SI Figure 16, but for all-atom data only.
