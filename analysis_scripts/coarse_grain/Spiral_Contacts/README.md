Get PDB files of each system ready to use as a reference for contacts calculations. Also combine all runs of a single system into one trajectory called 'combined_aligned.dcd'. Run the calculations scripts in 'contacts_calc_scripts/' to generate the '{system}\_tail_contacts_inside_outside_freq_SEM.dat' outputs in the 'results/CG_Spiral_Contacts_raw_data/' directory. Finally, just execute the 'plot_spiral_CG.ipynb' Jupyter notebook to plot the data as seen in SI Figure 13. To visualize a stepwise cumulative representation of the data, just execute the 'plot_stepwise_cumulativecontacts_CG.ipynb' notebook to get SI Figure 16.
