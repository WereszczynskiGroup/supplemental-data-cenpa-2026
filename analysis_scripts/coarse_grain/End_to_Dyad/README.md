Simply execute the 'data_calc_scripts/execute_etdscripts.sh' bash script via command line to generate the 'results/CG_etd_raw_data/' files, then execute the 'KL_divergence_calculator.ipynb' notebook to calculate the Kullback-Leibler divergence values of each system using both H3 and CENP-A NCPs as separate references for dual calculations (stored in 'results/CG_etd_raw_data/KL_divergence_with_error.tsv'. Then, use the provided Jupyter notebook 'hist_all_sys.ipynb' which pulls from the output files of both calculation scripts to plot the End-to-Dyad coarse-grained data shown in the main text figures 1-6 and SI figure 14.

To see extra time-series EtD data, simply execute the python scripts in the 'time_series_plotting_scripts/' directory, which use the same data outputs from the calculation scripts. Note that the time-series data includes equilibration time data, so the plotting axes may need to be adjusted depending on what the user is attempting to visualize and what data is available. To calculate EtD with equilibration data as seen from the plots, simply uncomment the trajectories in the calculation scripts and rerun them.
