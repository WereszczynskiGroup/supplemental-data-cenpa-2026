Execute the 'RMSF_tail_gen_aligned_to_H4only.sh' bash script which will calculate all the RMSF values using the provided .psf and necessary trajectories as inputs. The trajectories may be available upon request, but are simply the full post-equilibration coarse-grained trajectories of each replica of each system. This will generate the files in 'results/CG_RMSF_raw_data/' for all runs combined or per replica for each system. The 'plot_all_tail_RMSFs.ipynb' notebook can then be executed to generate the plots of the N-terminal region RMSF values shown by SI figure 15.
