# Supporting Information for "Determinants of centromeric nucleosome conformation"

This repository contains simulation input files, analysis scripts, and processed data for:

**Determinants of centromeric nucleosome conformation"**, E.A. Paintsil, J. Lee, S.S. Meidl Zahorodny, J. Wereszczynski, and E.A. Morrison, *bioRxiv*, 2026
DOI: [10.64898/2026.05.15.724335](https://doi.org/10.64898/2026.05.15.724335)

## Directory Structure
- `input_files/`: Simulation setup files (PDB, config, etc.)
- `analysis_scripts/`: Analysis scripts (e.g., End-to-Dyad, Contacts, MM/GBSA) and plotting scripts that use the 'results/' raw output data
- `results/`: Output files generated by analysis scripts and used for plotting
- `figures/`: Figures included in the paper

Data archive on Zenodo:


Trajectory files have been deposited on Zenodo. These files are water-stripped and strided for size reduction, but cover the full simulation time and support reproduction of results.
Adjustments to analysis scripts/notebooks in regards to reading/plotting may be needed depending on how many frames are available per trajectory. Trajectory names are slightly different on Zenodo 
than may be used in the analyses, but the data is the same. Trajectory skips of every 100 and 10 frames are done for all-atom and coarse-grain, respectively, to keep file sizes low. For coarse-grained 
analyses, any .psf required may be found in the 'analysis_scripts/coarse_grain/RMSF/PSF_files/' directory.
