# Supporting Information for "Determinants of centromeric nucleosome conformation"

This repository contains simulation input files, analysis scripts, and processed data for:

**Determinants of centromeric nucleosome conformation"**, E.A. Paintsil, J. Lee, S.S. Meidl Zahorodny, J. Wereszczynski, and E.A. Morrison, *bioRxiv*, 2026
DOI: [10.64898/2026.05.15.724335](https://doi.org/10.64898/2026.05.15.724335)

## Directory Structure
- `input_files/`: Simulation setup files (PDB, config, etc.)
- `analysis_scripts/`: Analysis scripts (e.g., End-to-Dyad, Contacts, MM/GBSA) and plotting scripts that use the 'results/' raw output data
- `results/`: Output files generated by analysis scripts
- `figures/`: Figures included in the paper
